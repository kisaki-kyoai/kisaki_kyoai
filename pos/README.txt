絹彩喜 iPadレジ

【公開方法】
GitHub Pagesで公開しているリポジトリに kisaki-pos フォルダの中身を pos/ フォルダとしてアップロードしてください。
例: https://kisaki-kyoai.com/pos/
既存の index.html を上書きしないでください。

【iPadへの設定】
1. iPadのSafariで https://kisaki-kyoai.com/pos/ を開く。
2. Safariの共有メニューから「ホーム画面に追加」。
3. ホーム画面からレジを開き、オンライン状態で画面が完全に読み込まれるまで待つ。
4. 在庫タブで初期在庫数を登録する。
5. 機内モードにして、レジが起動・操作できることを事前にテストする。
6. 実際の会計をテストした場合は、取消または初期化してから本番を開始する。

【注意】
・売上データは使用するiPad内だけに保存されます。端末間では共有されません。
・ブラウザのデータ削除、端末紛失・故障などで失われる可能性があります。こまめに「全データをバックアップ」してください。
・iPadのプライベートブラウズでは使わないでください。
・CSVとJSONの保存先はiPadの「ファイル」アプリなどを確認してください。
・会計取り消しでは売上の状態を取消済みに変更し、在庫を戻します。
・在庫タブの値は「追加数」ではなく「現在庫数」です。
・このレジはレシート印刷、税務帳票、複数端末同期には対応していません。
